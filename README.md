# Sales Project

R project that analyzes product sales and creates a bar chart.

## Files

- `analysis.R` — complete R code
- `data/sales.csv` — sample dataset
- `ANALYSIS.md` — short explanation of the results
- `sales_results.csv` — generated results table
- `sales_chart.png` — generated chart

## How to run

1. Open the `tiny_r_sales_project` folder as an RStudio project or set it as your working directory.
2. Open `analysis.R`.
3. Click **Source**, or run:

```r
source("analysis.R")
```

The script prints the results and creates `sales_results.csv` and `sales_chart.png`.
